# csv-banking-manager-system
A Python CLI banking app with CSV persistence, featuring auto-registration for new users, password authentication, balance management, and account updates.
🏦 Python Banking System

A command-line banking application built with Python, featuring user registration, password authentication, balance management, account updates, and CSV-based data persistence.

✨ Features

* User Registration: Automatically registers new users when they create an account.
* Password Authentication: Validates user passwords during login.
* Balance Management: Allows users to view and manage their account balances.
* Account Updates: Enables users to update their account information.
* CSV Data Persistence: Stores account information in CSV files to retain data between sessions.
* Command-Line Interface: Provides a simple, interactive terminal-based experience.

🛠️ Technologies Used

* Python
* CSV File Handling
* File I/O
* Functions and Data Structures
* Conditional Statements and Loops

🚀 Getting Started

Prerequisites

* Python 3 installed on your computer.

Installation

1. Clone the repository: (https://github.com/fjerfawaz14/csv-banking-manager-system/tree/main)
2. Navigate to the project directory:[main.py](https://github.com/user-attachments/files/33391464/main.py)
3. Run the application: python main.py

📂 Data Storage

The application uses CSV files to store user account information, allowing data to persist between program sessions.

🔐 Security Note

This project is intended for educational purposes. Passwords are currently stored in plain text. Secure password hashing and additional security measures are planned as future improvements.

This application is not intended for real banking or storing sensitive financial information.
